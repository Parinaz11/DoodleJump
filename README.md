# Doodle Jump (Unity 2D Game)

This project is a 2D platformer game inspired by **Doodle Jump**, developed using the Unity game engine as the final project for a Unity course.

Instead of the original character, the player controls a **crow**, which jumps across tree branches to climb as high as possible.

---

## Game Concept

The objective of the game is simple:

- Control the crow as it continuously jumps upward
- Land on branches to avoid falling
- Reach the highest possible score by climbing as far as possible

The game ends when the player falls off the screen.

---

## Gameplay Features

- Continuous upward jumping mechanic
- Procedurally generated platforms (branches)
- Physics-based movement using Unity Rigidbody2D
- Score tracking based on height reached
- Simple and responsive controls
- 2D animated character (crow)

---

## Controls

- Move left/right: Arrow Keys or A / D
- Automatic jumping when landing on a platform

---

## Game Design

Instead of traditional platforms, the environment is designed around a **forest theme**:

- Platforms are represented as **tree branches**
- The player character is a **crow**
- The visual style is kept simple and 2D for clarity and performance

---

## Technologies Used

- Unity Engine
- C# Programming Language
- Unity Physics (Rigidbody2D)
- 2D Sprite Rendering System

---

## How to Run

1. Open the project in Unity (recommended version: 2D-compatible Unity release)
2. Load the main scene
3. Press **Play** in the Unity Editor
4. Control the crow and start climbing
